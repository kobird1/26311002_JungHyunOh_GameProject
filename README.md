## 게임 소개

플레이어가 햄버거 음식점에서 손님의 주문을 받고, 음식을 조리해 직접 서빙하는 게임입니다. 제한 시간 동안 주문을 처리해 돈을 벌고 새로운 조리 기계와 테이블을 구매하는 것이 목표입니다.

## 게임 흐름

```text
손님 입장 → 주문 확인 → 음식 조리 → 트레이에 음식 담기
→ 손님에게 서빙 → 수익 획득 → 시설 확장
```

## 핵심 시스템

- 손님 입장, 주문, 기다림 및 퇴장
- 햄버거, 음료, 감자튀김 조리
- 트레이를 이용한 음식 조합과 서빙
- 제한 시간과 목표 매출
- 조리 기계 및 테이블 구매

## 조작 방법

| 키 | 기능 |
|---|---|
| 방향키 또는 WASD | 플레이어 이동 |
| Space | 주문받기, 조리, 음식 담기, 서빙 |
| ESC | 일시정지 |
