# 게임 기획서

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 게임명 | Burger Rush |
| 장르 | 2D 음식점 운영 / 타임 매니지먼트 |
| 개발 환경 | C++, glc2d_lib, Visual Studio 2022 |
| 목표 | 손님의 주문을 처리해 매출을 올리고 음식점을 확장한다. |

플레이어가 작은 햄버거 음식점에서 주문 확인, 조리, 서빙을 모두 담당하는 게임이다. 여러 손님의 주문 내용과 기다림 시간을 확인하며 처리 순서를 정하는 것이 핵심이다.

---

## 2. 핵심 게임 흐름

```text
손님 입장
→ 빈 테이블에 착석
→ 플레이어가 주문 확인
→ 음식 조리
→ 트레이에 음식 준비
→ 손님에게 서빙
→ 돈 획득
```

제한 시간 동안 위 과정을 반복한다. 영업이 끝나면 보유 금액으로 새로운 조리 시설이나 추가 테이블을 구매한 뒤 다음 영업일을 시작한다.

---

## 3. 조작 시스템

| 입력 | 기능 |
|---|---|
| 방향키 또는 WASD | 플레이어 이동, UI 커서 이동 |
| Space | 상호작용, UI 항목 선택 |
| ESC | 일시정지 |

---

## 4. 손님 시스템

손님은 다음 순서로 행동한다.

```text
입장 → 자리로 이동 → 주문 확인 대기 → 음식 대기
                                   ├→ 올바른 음식 → 식사
                                   │               → 돈과 빈 트레이를 남기고 퇴장
                                   ├→ 잘못된 음식 → 즉시 퇴장
                                   └→ 기다림 시간 종료 → 퇴장
```

- 영업 중 빈 테이블이 있을 때 손님이 입장한다.
- 자리에 앉은 손님에게 가까이 가면 플레이어 위에 상호작용 표시가 나타난다.
- 플레이어가 Space 키로 상호작용하면 주문 내용을 확인할 수 있다.
- 음식을 전달하면 손님 위에 손님 반응 표시가 나타난다.
- 올바른 음식을 받은 손님은 식사를 마친 뒤 테이블에 돈과 빈 트레이를 남기고 퇴장한다.
- 잘못된 음식을 받거나 기다림 시간이 끝난 손님은 식사하지 않고 바로 퇴장한다.
- 플레이어가 테이블을 정리하면 해당 테이블을 다시 사용할 수 있다.

---

## 5. 주문 시스템

- 주문은 현재 음식점에서 만들 수 있는 메뉴 중 무작위로 생성된다.
- 1일차에는 햄버거만 주문하며, 이후에는 서로 다른 메뉴를 최대 두 개까지 주문한다.
- 주문을 확인하면 손님 머리 위의 주문 말풍선에 주문 내용이 표시된다.
- 플레이어는 화면에 보이는 손님들의 주문 말풍선을 직접 확인해 음식을 준비한다.

예시:

```text
손님 A: 햄버거 + 음료
손님 B: 햄버거
```

---

## 6. 메뉴 및 조리 시스템

조리 시설 가까이에서 상호작용하면 조리가 시작된다. 일정 시간이 지난 뒤 다시 상호작용하면 완성된 음식을 가져올 수 있다.

| 메뉴 | 조리 방식 | 조리 시간 | 판매 가격 |
|---|---|---:|---:|
| 햄버거 | 그릴에서 패티를 조리한 뒤 햄버거 조립대에서 완성 | 패티 5초 + 조립 2초 | 200원 |
| 감자튀김 | 튀김기에서 조리 | 6초 | 300원 |
| 음료 | 음료 기계에서 준비 | 3초 | 200원 |

- 조리 중인 시설에는 조리 게이지를 표시한다.
- 완성된 음식은 플레이어가 가져갈 때까지 시설에 남아 있다.
- 음식이 타거나 재료가 부족해지는 기능은 사용하지 않는다.

---

## 7. 트레이 시스템

- 트레이는 주방의 정해진 위치에 항상 놓여 있다.
- 플레이어가 완성된 음식을 들고 트레이 가까이에서 상호작용하면 음식이 트레이에 올라간다.
- 트레이에는 음식을 최대 두 개까지 올릴 수 있다.
- 플레이어가 원하는 음식 구성을 완성한 뒤 완료한 트레이를 가져간다.
- 원하지 않는 음식 구성으로 만든 트레이는 쓰레기통에 버릴 수 있다.

예시:

```text
트레이: 햄버거 + 음료
```

---

## 8. 서빙 시스템

- 플레이어는 완료한 트레이를 가져와 손님 가까이에서 Space 키를 눌러 음식을 전달한다.
- 플레이어가 돈과 빈 트레이가 놓인 테이블 가까이에서 Space 키를 누르면 테이블을 정리하고, 돈을 획득한 뒤 빈 트레이가 사라진다.

---

## 9. 기다림 시스템

- 손님의 기다림 시간은 40초이다.
- 손님 머리 위에 기다림 게이지를 표시한다.
- 손님이 주문 확인과 음식을 기다리는 동안 기다림 게이지가 감소한다.
- 기다림 게이지가 0이 되면 주문이 취소되고 손님이 퇴장한다.

기다림 게이지를 통해 플레이어가 어떤 손님의 주문부터 처리할지 판단하게 한다.

---

## 10. 영업일 시스템

- 한 영업일은 2분 30초 동안 진행된다.
- 전체 게임은 3일의 영업일로 구성된다.
- 영업 시간이 끝나면 새로운 손님은 들어오지 않는다.
- 남아 있는 손님의 처리가 끝나면 영업 결과 화면으로 이동한다.
- 1일차와 2일차에는 영업 결과 화면에서 시설 구매를 마친 뒤 다음 영업일로 진행한다.
- 3일차 영업이 끝나면 최종 결과 화면으로 이동한다.

---

## 11. 보유 금액과 시설 확장 시스템

손님이 남긴 돈을 획득하면 보유 금액과 누적 매출에 반영된다. 시설을 구매할 때는 보유 금액을 사용하며, 게임의 최종 결과는 누적 매출을 기준으로 판정한다.

| 구매 항목 | 시설 가격 | 효과 |
|---|---:|---|
| 음료 기계 | 500원 | 손님이 음료를 주문할 수 있게 된다. |
| 튀김기 | 700원 | 손님이 감자튀김을 주문할 수 있게 된다. |
| 추가 테이블 | 600원 | 동시에 받을 수 있는 손님의 수가 증가한다. |

- 시설 가격은 영업 결과 화면에서 표시한다.
- 구매하지 않은 시설에는 잠금 표시를 출력한다.
- 음료 기계와 튀김기는 각각 한 번만 구매할 수 있다.
- 추가 테이블은 설치할 수 있는 위치가 남아 있는 동안 여러 번 구매할 수 있다.
- 구매한 시설과 추가 테이블은 다음 영업일부터 사용할 수 있다.

---

## 12. 게임 진행 구성

```text
타이틀 화면
→ Space 키로 시작
→ 1일차 영업
→ 영업 결과 화면
→ 2일차 영업
→ 영업 결과 화면
→ 3일차 영업
→ 최종 성공 또는 실패 판정
→ 최종 결과 화면
→ 1일차부터 다시 시작
```

---

## 13. 게임 시작 및 종료 조건

### 시작 조건

- 게임을 실행하면 타이틀 화면이 표시된다.
- 타이틀 화면에서 Space 키를 누르면 1일차 영업을 시작한다.

### 종료 조건

- 게임은 3일차 영업까지 진행된다.
- 3일차 영업이 끝나면 게임을 종료한다.
- 게임이 종료되면 최종 결과 화면으로 이동한다.
- 일시정지 화면에서 게임 종료 버튼을 누르면 진행 중인 게임을 종료하고 타이틀 화면으로 돌아간다.

### 성공 및 실패 조건

- 3일차 영업 종료 시 누적 매출이 목표 매출인 4,500원에 도달했는지를 기준으로 최종 결과를 판정한다.

---

## 14. 플레이어 행동 및 주요 게임 객체

### 플레이어 행동

- 플레이어는 방향키 또는 WASD로 음식점 내부를 이동한다.
- 상호작용 가능한 대상 가까이에서 Space 키를 눌러 상호작용한다.
- 손님과 상호작용하여 주문 내용을 확인한다.
- 조리 시설에서 조리를 시작하고 완성된 음식을 가져온다.
- 완성된 음식을 트레이에 올리고 손님에게 전달한다.
- 원하지 않는 음식 구성으로 만든 트레이는 쓰레기통에 버릴 수 있다.
- 돈과 빈 트레이가 놓인 테이블에서 상호작용하면 테이블을 정리하고, 돈을 획득한 뒤 빈 트레이가 사라진다.

음식, 트레이, 조리 시설과 가구는 플레이어가 상호작용하거나 관리하는 게임 객체로 사용한다.

### 주요 게임 객체

| 객체 | 역할 |
|---|---|
| 플레이어 | 음식점 내부를 이동하며 주문 확인, 조리, 운반, 서빙을 수행한다. |
| 손님 | 빈 테이블에 앉아 주문하고 음식을 기다린다. |
| 테이블 | 손님이 식사하며, 식사가 끝난 뒤 돈과 빈 트레이가 놓이는 장소이다. |
| 그릴 | 햄버거 패티를 조리한다. |
| 햄버거 조립대 | 조리된 패티로 햄버거를 완성한다. |
| 튀김기 | 감자튀김을 조리한다. |
| 음료 기계 | 음료를 준비한다. |
| 트레이 | 완성된 음식을 최대 두 개까지 올려 손님에게 전달하는 데 사용한다. |
| 음식 | 햄버거, 감자튀김, 음료로 구성되며 손님의 주문에 사용된다. |
| 쓰레기통 | 원하지 않는 음식 구성으로 만든 트레이를 버리는 데 사용한다. |
| 돈 | 식사를 마친 손님이 테이블 위에 남기며, 플레이어가 테이블을 정리할 때 획득한다. |
| 주문 말풍선 | 손님의 주문 내용을 표시한다. |
| 기다림 게이지 | 손님이 퇴장하기까지 남은 기다림 시간을 표시한다. |
| 조리 게이지 | 음식이 완성되기까지 남은 조리 시간을 표시한다. |
| 상호작용 표시 | 상호작용 가능한 대상 가까이에 있을 때 플레이어 위에 표시된다. |
| 손님 반응 표시 | 음식을 전달한 결과에 따라 손님 위에 표시된다. |
| 잠금 표시 | 아직 구매하지 않은 시설에 표시된다. |
| 추가 테이블 위치 표시 | 추가 테이블을 설치할 수 있는 장소를 표시한다. |

## 15. 게임 화면 구성

### 타이틀 화면

```text
┌──────────────────────────────────────────────────────────┐




                         BURGER RUSH



                      -Space를 눌러 시작-


└──────────────────────────────────────────────────────────┘
```

| 화면 요소 | 내용 |
|---|---|
| 배경 | 타이틀 화면 배경 표시 |
| 게임 로고 | 화면 중앙에 게임 제목 표시 |
| 시작 문구 | Space 키를 누르면 1일차 영업 시작 |

---

### 영업 화면

```text
┌──────────────────────────────────────────────────────────┐
  1일차                    02:30           누적 / 목표 매출
                                           1,250 / 4,500원
  [그릴] [햄버거 조립대] [튀김기] [음료 기계] ㅤㅤ [쓰레기통]
                  *
                  P                         ㅣ
 ────────────────── 카운터 ──────────────────┘

            [주문]
           [■■■■□□]
   □┌─$─┐□    C┌───┐□    · · · ·    · · · ·    · · · ·
   □└───┘□    □└───┘□    · · · ·    · · · ·    · · · ·
└──────────────────────────────────────────────────────────┘
```

화면 구성도에 사용한 `P`, `C`, `*`, `$`는 화면 배치를 설명하기 위한 임시 표시이다. 실제 게임에서는 각 항목에 해당하는 이미지를 사용한다.

| 화면 요소 | 내용 |
|---|---|
| 상단 정보 | 현재 영업일, 남은 시간, 누적 매출, 목표 매출 표시 |
| 주방 | 그릴, 햄버거 조립대, 튀김기, 음료 기계, 쓰레기통 배치 |
| 플레이어 | 플레이어 캐릭터 이미지를 사용하며 음식점 내부를 이동 |
| 상호작용 표시 | 상호작용 가능한 대상 가까이에서 플레이어 위에 전용 이미지 표시 |
| 손님 | 손님 캐릭터 이미지를 사용하며 테이블에 착석 |
| 주문 말풍선 | 손님 머리 위에 주문 내용 표시 |
| 기다림 게이지 | 손님 머리 위에 남은 기다림 시간 표시 |
| 돈과 빈 트레이 | 손님이 식사를 마치고 나간 뒤 테이블 위에 이미지로 표시 |
| 추가 테이블 위치 표시 | 추가 테이블을 설치할 수 있는 위치 표시 |

---

### 영업 결과 화면

```text
┌──────────────────────────────────────────────────────────┐
              ┌──────────────────────────────┐
                       1일차 영업 결과
              ├──────────────────────────────┤
                  오늘 매출          1,250원
                  성공한 주문            5개
                  떠난 손님              1명
                  보유 금액          1,250원
              ├──────────────────────────────┤
                [음료 기계] [튀김기] [테이블+]
                   500원     700원    600원
                        -다음 영업일-
              └──────────────────────────────┘
└──────────────────────────────────────────────────────────┘
```

| 화면 요소 | 내용 |
|---|---|
| 영업 결과 | 오늘 매출, 성공한 주문 수, 떠난 손님 수 표시 |
| 보유 금액 | 시설 구매에 사용할 수 있는 보유 금액 표시 |
| 시설 목록 | 구매할 수 있는 음료 기계, 튀김기, 추가 테이블 표시 |
| 시설 가격 | 각 시설을 구매하는 데 필요한 보유 금액 표시 |
| 다음 영업일 | 시설 구매를 마친 뒤 다음 영업일 시작 |
| 떠난 손님 | 잘못된 음식을 받거나 기다림 시간이 끝나 퇴장한 손님 수 표시 |

| 화면 요소 | 내용 |

## 18. 제작 범위 및 구현 우선순위

본 기획서의 1~17번 항목은 게임의 전체적인 완성 형태를 기준으로 작성하였다.

개발 과정에서는 게임의 핵심 흐름이 처음부터 끝까지 정상적으로 진행되는 것을 우선 목표로 한다.

1\~6단계는 반드시 완성할 핵심 구현 범위이며, 7\~8단계는 핵심 기능을 완성한 이후 개발 일정에 따라 추가하는 선택 구현 범위이다.

### 핵심 구현 범위

```text
1단계
플레이어 이동과 기본 충돌 처리

2단계
손님 생성, 빈 테이블 배정, 주문 확인

3단계
패티 조리, 햄버거 조립, 트레이 준비

4단계
손님 서빙, 식사, 돈 획득, 테이블 정리

5단계
기다림 시간, 영업 제한 시간, 매출 계산, 영업일 진행

6단계
타이틀, 영업 결과, 최종 결과와 다시 시작
```

### 선택 구현 범위

```text
7단계
시설 구매, 감자튀김, 음료, 복합 주문

8단계
추가 테이블, 애니메이션과 추가 사운드
```
